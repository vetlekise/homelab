# Vetle's Homeprod

Production-grade self-hosting at home. The goal is to run it the way you would run a professional service: up to date documentation (/s), automated certificate rotation, a strong security posture, and everything defined as code.

Feel free to copy whatever, and even use it as a framework to build your own.

> [!WARNING]
> This project is a work in progress and changes quickly. Expect breaking changes, renamed files and shifting conventions without notice.
