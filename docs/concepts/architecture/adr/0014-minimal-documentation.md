# 0014. Document only what is specific to this homelab

## Status

Accepted

## Date

2026-11-08

## Context

Upstream projects already document installation and usage. Copies go stale and cost effort to maintain.

## Decision

Link to upstream documentation instead of copying it. Document only what is specific to this homelab or hard to find elsewhere, such as design choices, workarounds, and manual steps. State each fact once and link to it.

## Consequences

- Guides are short and exist only for custom or obscure procedures.
- Upstream links can break, so link to specific pages where it matters.
